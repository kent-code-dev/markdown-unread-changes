# Markdown Unread Changes

Markdown ファイルの、前回読んだときからの変更箇所を、VS Code 標準の Markdown プレビューで色付けする拡張機能です。

AI アシスタントや他の人がノートを書き換えたとき、どこが変わったのかを、Git を使わずに確認できます。

## 機能

- **標準のプレビューで色付け**
  - 黄色：変更されたブロック
  - 緑：追加されたブロック
  - 赤：削除された内容（取り消し線で表示）
- **変更前のテキスト**：変更されたブロックにマウスを乗せると、変更前の内容を表示します。クリックすると、その場に展開します。
- **表**：変わった行だけに色を付けます。列の増減や配置の変更は、表全体を枠で囲んで示します。
- **ステータスバー**
  - `変更 3件`：表示中のファイルの変更箇所の数。クリックすると、そのファイルを既読にします。
  - `未読 2ファイル`：クリックすると、未読のファイルの一覧を開きます。選んだファイルは、初期設定ではプレビューで開きます。
  - `未読なし`：未読のファイルはありません。
- **コマンド**（コマンドパレットから実行）
  - `Markdown Unread Changes: 表示中のファイルを既読にする`
  - `Markdown Unread Changes: すべてのファイルを既読にする`（確認のダイアログが出ます）
  - `Markdown Unread Changes: 未読のファイルの一覧を表示する`

初めて起動したときに、ワークスペース内の Markdown ファイルをすべて「既読」として取り込みます。その後に変更されたファイルは、既読にするまで「未読」になります。設定の変更などで追跡の対象が広がったときも、新しく対象になったファイルは「既読」として取り込みます。

## 設定

| 設定 | 初期値 | 内容 |
|---|---|---|
| `markdownUnreadChanges.include` | `["**/*.md"]` | 追跡するファイルの glob パターン |
| `markdownUnreadChanges.exclude` | `node_modules`、`.git`、`dist`、`out`、`build`、`vendor` | 除外するファイルの glob パターン（`files.exclude` に指定したものも除外します） |
| `markdownUnreadChanges.maxFiles` | `2000` | 追跡するファイル数の上限。超えた場合は、開いたファイルだけを追跡します |
| `markdownUnreadChanges.maxFileSize` | `1024`（KB） | これより大きいファイルは追跡しません |
| `markdownUnreadChanges.openUnreadFileIn` | `preview` | 未読の一覧で選んだファイルを開く場所。`preview`（プレビュー。すでに開いていれば前面に出す）か `editor`（テキストエディタ） |

## 制限モード（信頼していないフォルダ）

制限モードでも、色付け・変更前のテキストの表示・ステータスバーはそのまま動きます。

ただし制限モードの間は、フォルダ側（ワークスペースの `.vscode/settings.json` など）に書かれた上の設定と `files.exclude` を無視し、ユーザー設定と初期値で動きます。フォルダを信頼すると、フォルダ側の設定を反映して取り込み直します（新しく対象になったファイルは「既読」として取り込みます）。

## 制限事項

- **文字コードは UTF-8 だけに対応しています。** Shift_JIS など UTF-8 以外のノートでは、開いた・閉じただけで未読になったり、変更前のテキストが文字化けしたりします。
- **名前の変更**：VS Code のエクスプローラーなどで名前を変えた・移動したファイルは、既読の状態を引き継ぎます。Git や他のアプリなど VS Code の外で名前を変えると、「削除と新しいファイル」として扱い、ファイル全体が追加（緑）・未読になります。
- **保存する容量**：追跡しているファイルの複製（スナップショット）を、拡張機能の保存先に置きます。初期設定の上限では、最大でおよそ 2000 ファイル × 1MB です。制限モード（信頼していないフォルダ）でも同じように保存します。保存先は VS Code がワークスペースごとに用意するフォルダで、ワークスペースを消しても、VS Code が掃除するまで残ります。容量を抑えたいときは、`maxFiles`・`maxFileSize`・`include` で対象を絞ってください。
- **シンボリックリンク**：VS Code のファイル検索はシンボリックリンクをたどるため（`search.followSymlinks`）、リンク先がワークスペースの外でも取り込むことがあります。取り込んだ内容は外部に送らず、上の保存先に置くだけです。

## プライバシー

**拡張機能自体はインターネットに接続しません。**

- テレメトリ、利用状況の収集、エラー情報の送信は行いません。プレビュー用の CSS とスクリプトは拡張機能に同梱していて、拡張機能が追加で通信することはありません。
- ノートに書かれた外部の画像（`![](https://…)`）は、拡張機能ではなく VS Code 標準の Markdown プレビューが読み込みます。読み込むかどうかは VS Code の設定（`markdown.preview.security`）に従います。削除された内容と変更前のテキストは、ただの文字列として表示するので、そこに書かれた画像は読み込みません。
- 保存するのは、追跡している Markdown ファイルを既読にした時点の内容（スナップショット）だけです。VS Code がワークスペースごとに用意するローカルのフォルダ（`ExtensionContext.storageUri`）に保存し、設定の同期（Settings Sync）にも載せません。
- 実行時に使う外部のパッケージはありません。

ソースコードでは、通信に使う API を Lint のルールで禁止しています。パッケージを作るときは、ビルドした結果と CSS に URL や通信に使う API が含まれていないことも確かめています。
